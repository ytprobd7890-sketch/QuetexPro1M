# Quetex Pro 1M — ১ মিনিট এজ গাইড (বাংলা)

> এই ডকুমেন্টটা সত্যি কথা দিয়ে শুরু। ১ মিনিটের ক্যান্ডেল প্রেডিকশন কোনো জাদু না —
> এটা সম্ভাবনার হিসাব। যে টুল আপনাকে "৯০% উইন রেট" বলে, সে আপনাকে ঠকাচ্ছে।

## ১. মোবাইলে কীভাবে ব্যবহার করবেন (স্ক্রিনশট পদ্ধতি)

মোবাইল ব্রাউজারে **tab share কাজ করে না** — Chrome Android আর iOS Safari দুটোতেই
`getDisplayMedia()` API বন্ধ রাখা হয়েছে। তাই মোবাইলে পথটা হলো **স্ক্রিনশট**:

1. ব্রোকার চার্ট খুলুন (Quotex / Pocket Option / TradingView / Binance)।
2. টাইমফ্রেম **1m** করুন, আর এমনভাবে জুম করুন যাতে **২০–৫০টি ক্যান্ডেল** দেখা যায়
   এবং ক্যান্ডেলগুলোর মাঝে **সামান্য ফাঁক** থাকে। (ক্যান্ডেল জোড়া লেগে থাকলে পড়া যায় না।)
3. **স্ক্রিনশট নিন** (ফোনের সাধারণ স্ক্রিনশট)।
4. অ্যাপে **1M Edge → Upload** চেপে স্ক্রিনশটটা দিন।
5. ছবির উপরে **আঙুল দিয়ে টেনে** শুধু ক্যান্ডেলের অংশটা ক্রপ করুন —
   নিচের RSI/MACD প্যানেল, দামের অক্ষ, লেখা — সব বাদ দিন।
6. **"Analyse chart → next candle"** চাপুন।
7. উপরে দেখুন: **UP/DOWN**, সম্ভাবনা %, edge (পয়েন্ট), এবং **EV** (লাভ/লোকসানের হিসাব)।

ছবির উপরে সবুজ/লাল বাক্স দেখে বুঝবেন অ্যাপ ঠিক ক্যান্ডেল ধরেছে কি না।
না ধরলে **Colour sensitivity** বাড়ান, বা আরও জুম করে আবার স্ক্রিনশট নিন।

> ⚠️ শুধু **সবুজ/লাল** ক্যান্ডেল পড়া যায়। ব্রোকার যদি নীল/সাদা ক্যান্ডেল ব্যবহার করে,
> অথবা ব্যাকগ্রাউন্ড সাদা হয় — তাহলে **Paste candles manually** দিয়ে
> `open,high,low,close` বসিয়ে দিন।

## ১.৫ সবচেয়ে দ্রুত পথ — Share Sheet (Android)

একবার অ্যাপটা ইনস্টল করে নিলে আর গ্যালারি/Upload-এ যেতে হবে না:

1. Chrome-এ অ্যাপ খুলুন → মেনু → **Add to Home screen** (বা কার্ডের **Install app** বোতাম)।
2. স্বাভাবিকভাবে ব্রোকার চার্টের **স্ক্রিনশট** নিন।
3. স্ক্রিনশট প্রিভিউতে **Share** → **Quetex 1M**।
4. অ্যাপ খুলে যাবে, ছবি লোড থাকবে → ক্রপ করে **Analyse**।

ছবি কোথাও আপলোড হয় না — পুরোটা আপনার ফোনেই প্রসেস হয়।
**iOS-এ** Share Target নেই; সেখানে **Upload** ব্যবহার করুন।

## ২. ডেস্কটপে (আসল tab share)

1. **Share tab** চাপুন → ব্রাউজার যে ট্যাব শেয়ার করতে বলবে, সেটা বেছে নিন।
2. ফ্রেমটা ছবি হিসেবে চলে আসবে → ক্রপ → **Analyse chart**।
3. একই ট্যাব আবার শেয়ার করলে নতুন ক্যান্ডেল পড়বে। (প্রতি মিনিটে একবার করাই যথেষ্ট।)

## ৩. লাইভ মোড (Binance)

`1M Edge` খোলার সময় BTC/ETH/SOL/BNB-এর **লাইভ ১ মিনিট** ডেটা আনার চেষ্টা করে।
পেলে:

- উপরে **LIVE** ব্যাজ, বড় কাউন্টডাউন (ক্যান্ডেল ক্লোজ হতে কত সেকেন্ড)।
- **Log call** চাপলে সেই কল রেকর্ড হয়, পরের ক্যান্ডেলে স্বয়ংক্রিয়ভাবে **জয়/হার** হিসাব হয়।
- নিচে **Session record**: কত কল, কত জিতেছে, হিট রেট, স্ট্রিক।

বাংলাদেশে অনেক সময় Binance ব্লক থাকে → অ্যাপ **DEMO** দেখাবে।
DEMO ডেটা দিয়ে আসল ট্রেড করা মানে টাকা জলে ফেলা। তখন স্ক্রিনশট পদ্ধতি ব্যবহার করুন।

## ৪. ইঞ্জিন কী দেখে সিদ্ধান্ত নেয়

১৪টি ফিচার, সবগুলো **স্কেল-মুক্ত** (ATR দিয়ে ভাগ করা), তাই দাম যতই হোক হিসাব একই:

| ফিচার | কী বোঝায় |
|---|---|
| ret1 / ret3 / ret5 | শেষ ১/৩/৫ ক্যান্ডেলের গতি (ATR-এ) |
| body | সিগন্যাল ক্যান্ডেলের বডি |
| wick | উপরের বনাম নিচের উইক — কে চাপ দিচ্ছে |
| rsi, rsiSlope | মোমেন্টাম ও তার দিক |
| emaSpread, emaSlope | EMA9−EMA20 এবং EMA20-এর ঢাল |
| vwapDev | VWAP থেকে দূরত্ব |
| rangePos | ২০-ক্যান্ডেল রেঞ্জে অবস্থান |
| streak | পরপর একই দিকের ক্যান্ডেল (৫টার পরে ফেরা) |
| volZ | ভলিউম স্বাভাবিকের চেয়ে কত বেশি |
| atrPct | ভোলাটিলিটির পার্সেন্টাইল |

- **লজিস্টিক রিগ্রেশন** শেষ ৭০% ডেটায় ট্রেন হয়, বাকি ৩০%-এ **out-of-sample** টেস্ট হয়।
  সেই হিট রেটটাই উপরে দেখানো হয়।
- **Trust shrinkage**: মডেল যদি ৫০%-এ ভ্যালিডেট হয়, তার প্রেডিকশন ৫০%-এর কাছেই টেনে আনা হয়।
  অর্থাৎ "ভুয়া আত্মবিশ্বাস" দেখাবে না।
- ৮০টির কম ক্যান্ডেল থাকলে (স্ক্রিনশটের সাধারণ কেস) **rule blend** চলে — সেটা
  ভ্যালিডেটেড মডেল না, শুধু কনটেক্সট। অ্যাপ নিজেই সেটা লিখে দেয়।

## ৫. হিসাবটা নিজে দেখুন — ৮৫% পেআউট

ব্রেক-ইভেন হিট রেট = `1 / (1 + payout)` = `1 / 1.85` = **৫৪.১%**

| মডেলের হিট রেট | $10 Stake-এ EV |
|---|---|
| 50% | −$0.75 |
| 52% | −$0.38 |
| 54% | −$0.02 |
| 55% | +$0.18 |
| 57% | +$0.55 |
| 60% | +$1.10 |

**মানে:** ৫০% বা ৫২% হিট রেট নিয়ে ট্রেড করলে আপনি **নিশ্চিতভাবে** হারছেন, ধীরে ধীরে।
অ্যাপের EV বক্সে এই সংখ্যাটাই দেখানো হয় — EV নেগেটিভ হলে ট্রেড করা মানে গণিতের বিরুদ্ধে লড়া।

### মার্টিংগেল কেন প্রাণঘাতী
$10 → $20 → $40 → $80 → $160 → $320 → $640। সাত ধাপে ~$1,270 লাগে,
আর ৭ বার পরপর হারার সম্ভাবনা মোটেও বিরল (৫০% হিট রেটে ~০.৮%, কিন্তু একদিনে
আপনি ৫০+ ট্রেড নিলে প্রায় নিশ্চিতভাবে একবার ঘটবে)। একবার ঘটলেই অ্যাকাউন্ট শেষ।
